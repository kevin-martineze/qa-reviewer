# Plan para cerrar la versión 1

Qué falta para dar QA Reviewer por terminado, las decisiones que lo destraban y las tareas en orden. Referencias: [PRD de la web](prd.md), PRD del API (`qa-reviewer-api/docs/prd.md`) y las hojas de ruta de ambos README. Estado al 31 de octubre de 2026.

Kevin revisa este plan antes de ejecutarlo. Las decisiones marcadas con **Confirmar** cuestan dinero, exponen datos o son difíciles de revertir; el resto se toma como decidido salvo que diga lo contrario. Cada decisión confirmada se vuelve un ADR (0011 en adelante).

### 2.3 Producto y contrato

| Tema                  | Decisión                                                                                                                                                                                                                                | Motivo                                                                                                                   | Confirmar              |

| Plugin: versiones     | `version` fijo en `plugin.json` (semver) que se sube en cada release de la skill, con tag `skill-vX.Y.Z` y CHANGELOG en `skill/`. `GET /skill/project` responde `minSkillVersion` y el cliente pide `/plugin update` si se quedó atrás. | Sin versión fija, cada commit le llegaría a todos.
